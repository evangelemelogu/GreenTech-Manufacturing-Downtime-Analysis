# Source Data

This folder contains the four source datasets used for the GreenTech Manufacturing Downtime Analysis.

## Files

- `line_productivity_batches.csv` — production batch, operator and productivity information.
- `line_downtime.csv` — downtime recorded against production batches.
- `downtime_factors.csv` — downtime causes and factor classifications.
- `products.csv` — product specifications and production requirements.

The datasets were validated and transformed in SQL Server before being analysed in Power BI.
